# Glossary · Glossário

| Term | Termo | Meaning · Significado |
|---|---|---|
| **Core** | **Núcleo** | Generic part of Reldor; knows nothing about a technology. · Parte genérica do Reldor; não conhece nenhuma tecnologia. |
| **Module** | **Módulo** | Everything about one technology (`modules/sf` for Salesforce). · Tudo de uma tecnologia (`modules/sf` para Salesforce). |
| **Index** | **Índice** | Summary of the project's metadata: names and links, never records or code bodies. · Sumário dos metadados: nomes e ligações, nunca registros nem código. |
| **Chain** | **Cadeia** | Classes reached from a trigger, through the fflib `Application` factory. · Classes alcançadas a partir de uma trigger, passando pela fábrica `Application` do fflib. |
| **Order of execution** | **Ordem de execução** | The sequence Salesforce follows when a record is saved, as `explain` shows it. · A sequência que o Salesforce segue ao salvar um registro, como o `explain` mostra. |
| **Cascade** | **Cascata** | A child save that recalculates and saves its parent (roll-up). · Salvar o filho recalcula e salva o pai (roll-up). |
| **Bypass switch** | **Bypass** | Custom setting or custom metadata the code reads to turn automations off. · Custom setting ou custom metadata que o código lê para desligar automações. |
| **Certainty** | **Certeza** | certain · likely · possible (text only). · certo · provável · possível (só em texto). |
| **Advisor** | **Conselheiro** | A skill that steps in before code, with one question and no blocking. · Skill que entra antes do código, com uma pergunta e sem bloquear. |
| **Environment chain** | **Cadeia de ambientes** | Branches in promotion order, for example develop → uat → production. · Branches na ordem de promoção, por exemplo develop → uat → produção. |
| **Clean commit** | **Commit limpo** | A commit with only the developer's lines, not what a retrieve brought. · Commit só com as linhas do dev, não o que veio do retrieve. |
| **Promotion rehearsal** | **Ensaio de promoção** | A simulated merge that shows conflicts, missing dependencies and commit order before the PR. · Merge simulado que mostra conflitos, dependências faltando e ordem dos commits antes do PR. |
| **Profile (project)** | **Perfil do projeto** | `.reldor/profile.md`: framework, patterns and team rules, versioned in the client's repo. · `.reldor/profile.md`: framework, padrões e regras do time, versionado no repositório do cliente. |
