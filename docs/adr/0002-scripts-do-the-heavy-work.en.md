# 0002 · Scripts do the heavy work

Facts about the org (automations, order of execution, references, conflicts) are computed by deterministic
scripts from an index. The AI only interprets requests and explains results. This keeps answers repeatable, cheap in
tokens and safe to trust. Skills must never ask the AI to discover these facts by reading files on its own.
