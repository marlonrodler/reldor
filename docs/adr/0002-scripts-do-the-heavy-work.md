# 0002 · Scripts do the heavy work · Scripts fazem o trabalho pesado

**EN.** Facts about the org (automations, order of execution, references, conflicts) are computed by deterministic
scripts from an index. The AI only interprets requests and explains results. This keeps answers repeatable, cheap in
tokens and safe to trust. Skills must never ask the AI to discover these facts by reading files on its own.

**PT.** Fatos sobre a org (automações, ordem de execução, referências, conflitos) são calculados por scripts
determinísticos a partir de um índice. A IA só interpreta pedidos e explica resultados. Assim as respostas são
repetíveis, baratas em tokens e confiáveis. As skills nunca pedem à IA para descobrir esses fatos lendo arquivos sozinha.
